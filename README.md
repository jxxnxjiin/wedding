# Easy Wedding MVP

Next.js 기반 Easy Wedding MVP 프로토타입입니다.

## 최초 실행

```bash
npm install
npm run dev
```

브라우저에서 접속:

```bash
http://localhost:3000
```

## 개발 서버 포트 변경

```bash
npm run dev -- -p 3001
```

접속:

```bash
http://localhost:3001
```

## 빌드 확인

```bash
npm run build
```

## 프로덕션 실행

```bash
npm run build
npm run start
```
